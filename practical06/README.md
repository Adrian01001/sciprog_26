# Practical 6

This practical guided us through matrix multiplication, first defining matrices $A$ and $B$, and then their product $C=AB$.

The code is split into two files, namely `main.c` for the skeleton of the code and printing, and `matmult.c` for the implementation of matrix multiplication. The files are linked by `matmult.h`.

```bash
# To run the code
make
./matmult
```
