Practical 9

This practical was about magic squares. We had to check whether a given matrix had the same row sums, column sums, and diagonal (and off-diagonal) sums. This involved the following:

- Creating an array of int arrays
- Filling the array with integers read from a file
- Computing the mentioned sums

Run the file as follows:

```bash
gcc -o out main.c
./out
# The program will ask you for a filename and tell you if the matrix within is a magic square.
```
