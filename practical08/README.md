# Practical 8

This practical was shorter than the others, and required us to write the Euclidean algorithm in both a recursive and iterative fashion, given the pseudo-code for both.

The files require the user to input two non-negative integers and it outputs their GCD using both methods. All pairs of integers I have tested return the same values in both methods.

```bash
# To run the file
gcc -o out GreatestCommonDivisor.c
./out
```
